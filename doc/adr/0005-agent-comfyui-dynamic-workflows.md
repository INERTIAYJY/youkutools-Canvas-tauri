# ADR 0005：允许内部助手发现并执行 ComfyUI 动态工作流

## 状态

已接受，2026-08-12。

## 背景

AI Canvas 已能运行用户导入的 ComfyUI 工作流，也已通过 `/object_info` 检查工作流缺失节点，但内部助手只能看到应用中预先配置的媒体模型和已导入工作流。用户希望助手直接读取当前 ComfyUI 实例已安装的模型与全部注册节点，自行编写 API 格式工作流，并请求 ComfyUI 生成图片、视频或音频。

ComfyUI 的自定义节点没有统一的能力声明。一个已注册节点可能读写文件、访问网络、启动外部程序或产生其他无法由 AI Canvas 从 `/object_info` 推断的副作用。因此，允许全部节点不能等同于把任意工作流直接交给 `/prompt`，也不能绕过现有 `media_generation` 逐次确认策略。

## 决策

1. 模型和节点只通过当前 ComfyUI 服务 API 发现，不扫描 ComfyUI 安装目录或模型目录。
2. 优先使用 `/models` 和 `/models/{folder}` 获取模型分类与文件；旧版接口不可用时，从 `/object_info` 中加载器节点的 combo 选项回退发现。
3. 内部助手通过三个独立工具完成“发现 → 校验 → 执行”：
   - `comfyui_discover` 读取模型或节点定义；
   - `comfyui_validate_workflow` 校验助手编写的 API 工作流；
   - `comfyui_execute_workflow` 执行校验产生的短期 `validationId`。
4. 工作流允许使用 `/object_info` 当前注册的全部节点，包括所有自定义节点，不维护固定节点白名单。
5. 执行前必须验证工作流体积、节点数量、`class_type`、必填输入、节点连接、combo 选项和输出节点。未注册节点、悬空连接或当前实例不接受的模型/选项不得提交。
6. 校验通过的工作流只缓存在内存中十分钟，并绑定 `taskId`、`projectId` 和 ComfyUI 服务地址。执行工具只接收 `validationId`，不能用未经校验的 JSON 替换缓存内容。
7. `comfyui_execute_workflow` 使用 `media_generation` effect，每次执行都必须由用户确认。审批摘要展示节点数量、模型文件、自定义节点，并明确自定义节点可能具有文件、网络或外部程序能力。
8. 动态执行工具不向 MCP 暴露，防止外部客户端直接触发任意自定义节点。只读发现和校验仍受 Tool Registry、任务工具白名单与 Plan 模式约束。
9. 执行复用 ComfyUI `/prompt`、历史轮询、输出解析和媒体回填语义。取消本地任务后，优先调用任务取消 API，并兼容旧版队列删除与中断接口。
10. 动态工作流和 API 发现结果不进入 IndexedDB；生成产物按现有项目媒体规则尝试落盘。
11. 动态工作流成功执行后生成一个有效期一小时、绑定项目与对话的保存凭证。工具结果要求助手询问用户是否保存，禁止自动保存；用户明确同意后，`comfyui_save_workflow` 以 `file_write` effect 再次确认并写入现有工作流管理。
12. 保存时按媒体类型自动归类，复用现有 IO 节点识别逻辑生成 `ioNodes` 和默认输入节点；只保存 API 工作流，不伪造 ComfyUI 画布布局数据。

## 非功能要求

- **安全性**：原始工作流不能绕过校验令牌直接执行；执行始终确认；MCP 禁止调用动态执行工具。
- **兼容性**：支持新旧 ComfyUI 模型发现接口；节点契约以当前实例实时 `/object_info` 为准。
- **可恢复性**：校验令牌只在当前运行期短暂有效，服务地址变化后必须重新发现和校验。
- **性能**：模型与节点 API 结果缓存 30 秒；发现结果限制数量和回传体积，避免把完整大型节点目录一次塞进模型上下文。
- **可取消性**：本地 AbortSignal 立即停止等待，并尽力取消已提交的远端任务。
- **可审计性**：审批卡展示实际模型和自定义节点，执行仍记录为 Agent 的媒体生成步骤。
- **可控持久化**：工作流只有在执行成功、助手询问、用户同意并通过写入确认后才会进入工作流管理。

## 失败策略

- ComfyUI 未配置、不可达或返回无效数据时，发现和校验返回明确错误，不创建校验令牌。
- `/models` 不可用时自动回退到 `/object_info`；单个模型分类读取失败不会阻断其他分类。
- 工作流校验失败时最多汇总前十二项错误，避免错误内容撑满对话上下文。
- 用户确认前校验过期、项目变化或服务地址变化时拒绝执行，并要求助手重新校验。
- ComfyUI 接受工作流后执行失败时展示其历史错误；输出中没有目标媒体时按失败处理。
- 生成成功但项目落盘失败时保留 ComfyUI 原始结果地址，并把“生成成功”和“保存失败”分开报告。
- 工作流保存凭证过期、跨项目、跨对话或已使用时拒绝保存；持久化失败时保留凭证，允许用户在有效期内重试。

## 未采用方案

- **扫描 ComfyUI 模型目录**：不支持远程实例和额外模型路径，也会扩大本地文件权限。
- **固定安全节点模板**：风险最低，但无法满足使用全部已安装自定义节点的需求。
- **未经校验直接提交助手 JSON**：实现简单，但模型幻觉或过期节点定义会直接进入执行队列。
- **把原始工作流放进审批调用**：用户等待期间工作流内容可被替换或误传；任务绑定的校验令牌更容易保证确认对象与执行对象一致。
- **自动保存每个助手工作流到工作流库**：增加持久化噪声；首版只执行，后续可按用户明确操作保存。
- **执行成功后立即弹出保存窗口**：会打断结果查看，也绕过对话中明确表达保存意图的交互；改为由助手询问并调用受 Policy 保护的保存工具。

## 影响

- 使用自定义节点的最终风险由用户在每次审批时承担；AI Canvas 只能验证接口契约，不能证明节点内部实现安全。
- 节点或模型安装状态变化后，缓存最多延迟 30 秒刷新；执行前 ComfyUI 仍会做最终服务端校验。
- 助手需要按需查询节点定义，不能假设不同 ComfyUI 实例拥有相同节点和输入结构。
- 单次动态执行返回首个匹配的目标媒体；多输出批量交付不在本次范围内。
- 助手保存的是可执行 API 工作流；首次在 ComfyUI 中打开时没有原始 UI 布局，但可在 ComfyUI 中重新排版并保存回来。

## 回滚

移除 `comfyAgentService`、`comfyTools` 及其注册入口，并从 MCP 禁止列表删除动态执行工具 ID。回滚不涉及数据库、Tauri 安全配置、用户工作流或项目文件；原有导入工作流执行链路保持不变。
