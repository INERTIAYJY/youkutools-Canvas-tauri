# 项目模型路由与视觉上下文实施计划

## 目标

让对话助手优先使用项目设置中的文本模型，并让 Agent 在视觉模型与纯文本模型下都能理解用户显式引用的项目图片。

## 阶段

### 1. 项目默认对话模型

- 项目文本默认模型优先于应用级助手模型。
- 项目模型无效时回退到应用级模型。
- 主窗口和独立对话窗口的模型切换写回当前项目设置。
- 上下文预算使用实际生效模型。

### 2. 视觉模型 Base64 直传

- 在助手请求发送前解析 `@asset`、短剧资产和画布节点图片。
- 把本地、Blob、asset 和远程图片统一转换为受限 Base64 data URL。
- 单图上限 8 MB、最多 6 张、总计不超过 24 MB。
- 图片字节不进入消息、AgentTask 或项目记忆持久化。

### 3. 纯文本模型视觉桥接与模型路由

- 新增项目视觉理解模型设置与模型输入模态声明。
- 以内容指纹缓存客观图片描述，未修改图片重复引用不再次调用视觉模型。
- 纯文本模型只接收描述，并明确其为不可信素材说明。
- `app_get_state` 向 Agent 提供模型用途说明；自主模式可在未显式选择时按说明自动选择媒体模型，项目默认模型作为稳定回退。

## 验证

- 项目模型优先和失效回退测试。
- 视觉模型收到 Base64 多模态 content 测试。
- 描述指纹与缓存复用测试。
- 项目默认媒体模型与自主路由测试。
- IndexedDB 升级、索引与项目清理测试。
- TypeScript、定向 ESLint、全量 Vitest、生产构建、UTF-8 与差异检查。
