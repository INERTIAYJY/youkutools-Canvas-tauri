# 0.10.34 发版记录 — H.265 视频预览修复与导入自动转码

> 森之灵定制版（`INERTIAYJY/youkutools-Canvas-tauri`）本地打包 + `gh` 手动发布热更。
> 按[发版流程-森之灵定制版](../发版流程-森之灵定制版.md)执行。

## 本版范围

- 修正 HEVC 编码探测漏判：Rust 探测改为头尾都覆盖，森之灵边下边写出的 MP4 把 `moov` 与 `hvc1` 放在文件尾，原实现只有文件大于 8MB 才补读尾部，4–8MB 短片被判成 unknown 跳过转码，表现为「偶尔」无法预览。
- 新增播放兜底修复：播放器报编码不兼容（错误码 3/4）时按节点已有文件路径重新探测并转码，成功后回写节点；全屏预览同样生效。
- 新增「导入自动转码H264」设置开关（默认开启）：外部拖入的 H.265 视频自动转成 H.264 并替换工程内副本，外部原文件不动，旧副本移入项目 `.trash` 可撤销。
- 容器识别扩展到 `.mp4` / `.m4v` / `.mov`；`VideoPlayer` 的 `onError` 传出媒体错误码。

## 发布方式

定制版 fork 的 Actions 对公开 fork 默认不触发，因此沿用**手动发布**（母项目 release.yml 的三平台矩阵不适用于本 fork）：

1. 构造 `latest.json`（含 `.sig` 内容与下载地址，URL 用 `.` 形式）
2. `gh release create v0.10.34` 上传安装包、签名与 `latest.json`，中文说明经 `--notes-file` 从 UTF-8 文件读取
3. 验证 `latest.json` 可访问、安装包可下载
