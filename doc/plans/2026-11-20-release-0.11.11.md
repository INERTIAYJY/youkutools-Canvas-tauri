# v0.11.11 发版准备：森之灵仅 CLI 登录

## 范围

移除 AI Canvas 应用侧森之灵 API Token 认证方式，保留 Seedling CLI 浏览器授权登录。遗留 Seedling API Token 不作迁移清理；不用于模型可用性、模型目录、生成、Agent 授权或 CLI 命令。所有 Seedling 子进程屏蔽继承的 `SEEDLING_TOKEN`。

## 修改面

- 设置与连接 UI：移除 Token 输入、保存、清除；Seedling connection catalog 使用 `cli-session`，只有 CLI 登录后可用。
- 认证调用链：模型选择、目录加载、普通生成与 Agent 工具均要求 `seedlingAuth.loggedIn`；invoke 不再传 `apiToken`。
- Rust：Seedling commands 不再接受 Token 参数或向 CLI 注入 Token；使用 `env_remove` 阻断机器级遗留环境变量。
- 文档：更新用户认证说明、历史集成说明和发布说明；保留 CLI 登录凭据行为。

## 兼容性与安全

- 旧版 `config.providers.seedling.apiKey`／secret store 项不清除，避免静默删除用户凭据；它们不再参与本应用认证。编辑已有 Seedling 连接时不覆盖该惰性字段。
- CLI browser login 仍由 Seedling CLI 自己维护；本应用命令强制忽略 `SEEDLING_TOKEN` 环境变量。
- 版本 0.11.11（若标签/Release 已存在不得覆盖，需切换到新补丁版本）。
