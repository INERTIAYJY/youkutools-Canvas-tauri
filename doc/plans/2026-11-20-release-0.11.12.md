# v0.11.12 发版准备：森之灵仅 CLI 登录

## 版本关系

v0.11.11 已作为不可变 Git 标签推送，但远端 Release 质量门在源码构建前失败：标签 SHA 对应的 `.github/release-title.txt` 仍是 v0.11.9，故 metadata title 不符合标签。该标签不移动、不覆盖。此补丁将相同认证变更发布为 v0.11.12，修正 title 与 release notes 后新建不可变 tag。

## 功能范围

- 移除森之灵 API Token 设置、接入目录凭据及应用 invoke 参数，认证仅由 Seedling CLI 浏览器登录态提供。
- Rust commands 不再接收 Token，CLI 命令清除继承的 `SEEDLING_TOKEN` 环境变量。
- 旧版配置中的 API Key 字段保留惰性兼容，不用作认证、不传递；不自动清除用户存储数据。
