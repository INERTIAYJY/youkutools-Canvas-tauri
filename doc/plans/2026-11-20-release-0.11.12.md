# v0.11.12 发版准备：森之灵仅 CLI 登录

## 版本关系

v0.11.11 已作为不可变 Git 标签推送，但远端 Release 质量门在源码构建前失败：标签 SHA 对应的 `.github/release-title.txt` 仍是 v0.11.9，故 metadata title 不符合标签。该标签不移动、不覆盖。此补丁将相同认证变更发布为 v0.11.12，修正 title 与 release notes 后新建不可变 tag。

## 功能范围

- 移除森之灵 API Token 设置、接入目录凭据及应用 invoke 参数，认证仅由 Seedling CLI 浏览器登录态提供。
- Rust commands 不再接收 Token，CLI 命令清除继承的 `SEEDLING_TOKEN` 环境变量。
- 旧版配置中的 API Key 字段保留惰性兼容，不用作认证、不传递；不自动清除用户存储数据。

## 本地构建证据

v0.11.11 源码已在本地成功签名构建，NSIS 与 MSI 及对应 `.sig` 均生成；未安装应用。远端质量门在 v0.11.11 `resolve` 阶段因 release title stale failure，后续 jobs skipped；签名 secrets 尚未被 workflow 验证。v0.11.12 修复 `.github/release-title.txt` 和版本 metadata 后需要重新打签名包和运行 Release 门禁。

## 发布门禁

Actions secret 名称 `TAURI_SIGNING_PRIVATE_KEY` 与 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` 已配置，值只由远端 job 验证；不读取或上传 secret 内容。提交需原子推送默认分支与 `v0.11.12`，等待同 SHA CI 和 Release workflow。不得移动/重写 v0.11.11 标签，不安装本地包。
