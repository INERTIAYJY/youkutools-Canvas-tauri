# v0.11.16：视频节点批量生成修复与森之灵失败诊断

## 范围

修复「关闭『在此节点生成』后生成 1-4 条到新建节点」在新项目结构（`modelGeneration === 1`）下必然报「请从原画布视频节点发起任务，无法验证输入时不提交」的问题，并补强森之灵批量生成的失败提示。

## 根因

- 「生成到新建节点」分支在 `AINodeDialog.runVideoToNewNodes` 中直接调用底层 `generateVideo`，绕过统一入口 `executeGeneration`；后者才注册原生提交守卫（`registerNativeVideoSubmissionGuard`）。新项目结构的 `generateVideo` 顶部会拒绝没有守卫的提交，所以每个新节点都在发出请求前失败。
- 该分支还绕过了媒体任务账本/恢复、画布派生守卫、用量账本与 H.265 兼容落盘，组件内另有一份重复实现。

## 修改

- 每个新建节点改为调用 `executeGeneration(node.id)`；删除组件内重复的落盘、转码、历史与错误写回逻辑。
- 新建节点数据显式写 `role: 'generator'` 并清空 `videoTaskState`、`mediaTaskState`、`mediaTaskStage`、`videoBatchFingerprint`。
- 森之灵任务失败提示补上任务号与原因；`SubmitFailed` 明确提示可重试。批量生成结束后汇总未成功条数与首个原因。
- 回归测试：`tests/components/nodeCriticalInteractions.test.tsx` 新增“每个新节点都走统一提交入口”的用例。

## 验证与边界

- 本地：lint、应用类型、测试类型通过；`tests/components/nodeCriticalInteractions.test.tsx` 244 项全绿；`tests/services/seedlingService.test.ts` 通过。
- 本机安装包实测：0.11.16 安装成功，注册表与可执行文件版本号均为 0.11.16。
- 森之灵 `SubmitFailed` 属服务端瞬时拒单（CLI 任务记录 `generationTaskId` 为空），应用不自动重投，需用户重试。
- v0.11.11–v0.11.15 标签保持不可变；本版为新的稳定补丁版本。
