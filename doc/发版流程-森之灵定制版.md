# 发版流程 — 森之灵定制版（fork 热更）

> 适用范围：**AI Canvas 森之灵定制版**（`INERTIAYJY/youkutools-Canvas-tauri`）的本地打包与 GitHub Release 热更发布。
> 与母项目发版（GitHub Actions CI）不同：定制版在本地打包 + `gh` 命令行发布，更新源只指向本项目 fork。

## 一、发布链路总览

```
本地改版本号 → 本地打包（带签名）→ gh 发布 Release → 用户端检查更新 → 从 fork 下载安装
```

- **更新源（endpoint）**：`https://github.com/INERTIAYJY/youkutools-Canvas-tauri/releases/latest/download/latest.json`（已配置）
- **隔离保证**：更新只认 fork 的 `latest.json`，与母项目版本号撞车无影响
- **版本策略**：沿用母项目序列独立递增（`0.8.9 → 0.8.10 → …`），两端互不干扰

## 三、发版步骤（每次发版）

### 1. 修改版本号

涉及 4 个文件（版本号须一致）：

| 文件 | 字段 |
|---|---|
| `package.json` | `version` |
| `src-tauri/tauri.conf.json` | `version`（决定安装包文件名） |
| `src-tauri/Cargo.toml` | `[package] version` |
| `src-tauri/Cargo.lock` | 项目自身 `version` 行 |

> ⚠️ 只改 `tauri.conf.json` 即可决定安装包名；Cargo 文件改动需一致，**避免用全局替换**（会误伤同名依赖，如 `avif-serialize 0.8.8` 的 checksum 校验）。

### 2. 提交并推送

```powershell
git add -A
git commit -m "chore(release): 发布森之灵定制版 vX.Y.Z"
git push origin master
```

### 3. 本地打包（带签名）

```powershell
$env:PATH = "C:\Users\yangjunyan\.cargo\bin;$env:PATH"
$env:CARGO_BUILD_JOBS = "4"
$env:TAURI_SIGNING_PRIVATE_KEY = (Get-Content "C:\Users\yangjunyan\.ai-canvas-signing\youkutools-canvas.key" -Raw).Trim()
$env:TAURI_SIGNING_PRIVATE_KEY_PASSWORD = "YK-Seedling-2026-X9k2"
npm run tauri build
```

产物在 `src-tauri/target/release/bundle/`：
- `nsis/AI Canvas_X.Y.Z_x64-setup.exe` + `.sig`（安装包 + 签名）
- `msi/AI Canvas_X.Y.Z_x64_en-US.msi` + `.sig`
- `latest.json` **不自动生成**——由发布工作流生成，本地需手动构造（见步骤 4）

> 打包成功标志：输出 `Finished X updater signatures` 且**无** `does not match the public key` 警告。

### 4. 生成 latest.json

更新清单需手动构造（含签名 + 安装包 URL）：

```json
{
  "version": "X.Y.Z",
  "notes": "Seedling customized build vX.Y.Z (updater points to fork)",
  "pub_date": "2026-08-18T08:17:16Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "<AI Canvas_X.Y.Z_x64-setup.exe.sig 文件内容>",
      "url": "https://github.com/INERTIAYJY/youkutools-Canvas-tauri/releases/download/vX.Y.Z/AI.Canvas_X.Y.Z_x64-setup.exe"
    }
  }
}
```

> ⚠️ **URL 中的资产名用 `.` 而非空格**（GitHub 会把上传资产名的空格规范化为 `.`）。

### 5. 发布到 fork Release

**Release 说明用中文**，通过 UTF-8 文件传入（避免 PowerShell 命令行中文乱码）：

```powershell
# 先写中文说明到 UTF-8 文件（内容按本次发布填写）
$notes = @"
## 森之灵定制版 vX.Y.Z

### 新增 / 优化
- ...

### 修复
- ...
"@
[IO.File]::WriteAllText("$env:TEMP\release-notes.md", $notes, (New-Object System.Text.UTF8Encoding($false)))
```

```powershell
$gh = "C:\Program Files\GitHub CLI\gh.exe"
$desktop = [Environment]::GetFolderPath('Desktop')

# 创建 Release 并上传资产（安装包 + 签名 + 更新清单），说明从文件读取（中文）
& $gh release create vX.Y.Z `
  "$desktop\AI Canvas_X.Y.Z_x64-setup.exe" `
  "$desktop\AI Canvas_X.Y.Z_x64-setup.exe.sig" `
  "$desktop\latest.json" `
  --repo INERTIAYJY/youkutools-Canvas-tauri --title "vX.Y.Z" `
  --notes-file "$env:TEMP\release-notes.md"

# 若需更新说明：编辑后重新传入
& $gh release edit vX.Y.Z --repo INERTIAYJY/youkutools-Canvas-tauri --notes-file "$env:TEMP\release-notes.md"

# 若需更新 latest.json：先删资产再上传（用无中文路径）
& $gh release delete-asset vX.Y.Z latest.json --repo INERTIAYJY/youkutools-Canvas-tauri --yes
& $gh release upload vX.Y.Z "$desktop\latest.json" --repo INERTIAYJY/youkutools-Canvas-tauri
```

> ⚠️ **上传路径避免含中文**（中文目录会导致 `gh release upload` 静默失败）；
> ⚠️ **Release 说明用中文**，务必经 `--notes-file` 从 UTF-8 文件读取，不要在命令行直接拼中文。

### 6. 验证发布

```powershell
# 1) latest.json 可访问且 URL 正确
$r = Invoke-WebRequest -Uri "https://github.com/INERTIAYJY/youkutools-Canvas-tauri/releases/latest/download/latest.json" -UseBasicParsing
# 2) 安装包可下载
$h = Invoke-WebRequest -Uri <latest.json 中的 url> -Method Head -UseBasicParsing
```

## 五、踩坑记录

| 问题 | 原因 | 对策 |
|---|---|---|
| `avif-serialize v0.8.8 checksum changed` | 全局替换版本号误伤 Cargo.lock 同名依赖 | 只改 `tauri.conf.json` 决定安装包名；Cargo 文件逐行精确修改 |
| 更新 URL 404 | GitHub 把资产名空格规范化为 `.`（`AI Canvas` → `AI.Canvas`） | latest.json 的 url 用 `.` 形式 |
| `gh release upload` 上传未生效 | 源文件路径含中文（`画布二号机`） | 复制到桌面等无中文路径再上传 |
| `0.8.8.1` 版本 updater 不识别 | 非标准 semver（四段） | 用标准递增（`0.8.9`、`0.9.0`） |
| 打包卡在密码输入 | 无密码密钥被当作加密密钥 | 用带密码私钥 + 设置 `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` |
| 签名警告 `does not match the public key` | 手动抄写公钥出错 | 从 `.pub` 文件读取，脚本写入 `tauri.conf.json` |
