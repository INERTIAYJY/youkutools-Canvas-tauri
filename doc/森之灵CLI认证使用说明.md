# 森之灵（Seedling）认证使用说明

> 适用对象：使用 AI Canvas 桌面版的用户。
> 森之灵视频生成仅支持 Seedling CLI 浏览器授权登录。

## 接入方式

AI Canvas 通过 Seedling CLI 执行模型目录读取、视频生成、任务查询与素材上传。应用设置页可检测、安装或更新 CLI；登录令牌由 CLI 自己管理，不经 AI Canvas 保存或传递。

1. 打开「设置 → 森之灵」，检查 CLI 状态；若未找到，点击「安装 CLI」。
2. 点击「开始浏览器授权登录」，在浏览器中确认配对码。
3. 返回应用，确认状态显示已登录，刷新可用模型列表。

登录会话有效期由 Seedling CLI／服务端决定；过期后重新完成浏览器授权。视频节点与对话 Agent 使用同一 CLI 登录态。

## API Token 说明

AI Canvas 只支持 Seedling CLI 浏览器授权登录，不提供应用侧 API Token 认证。旧配置中的 Token 为兼容保留，但不会用于认证或传递给 CLI。

## 常见问题

| 问题 | 处理办法 |
|---|---|
| CLI 显示未找到 | 点击「安装 CLI」并重新检测。 |
| CLI 未登录或登录失效 | 重新执行浏览器授权登录。 |
| 登录后模型列表为空 | 确认 CLI 显示已登录，点击「可用模型」旁的刷新；检查网络与 CLI 版本。 |
| 下载视频失败或任务卡住 | 在任务中心查看原任务状态；网络异常时对原任务执行查询或重试，避免重复提交。 |

## 安全

Seedling 登录凭据由 CLI 配置文件管理。AI Canvas 不提供或使用应用侧 API Token 认证；旧版保存的 Token 为避免破坏现有本地配置不会自动删除，但不用于认证、不会传给 Rust 命令或 CLI 子进程。若系统环境设有 `SEEDLING_TOKEN`，应用启动的 Seedling CLI 子进程会忽略它。
